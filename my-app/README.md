# my-app · App móvil de Reservas Deportivas

Aplicación React Native (Expo SDK 57 + Expo Router + TypeScript) del Trabajo Final Integrador de
Desarrollo para Móviles.

- Cómo instalarla, configurar la IP de la API y generar los builds: ver el
  [README de la raíz del repositorio](../README.md).
- Cómo está hecha, pantalla por pantalla: [`docs/04-app-movil.md`](../docs/04-app-movil.md).

```bash
npm install
cp .env.example .env.local     # y poner la IP de la API
npx expo start
```
